# output

## Purpose

Hold the package a human receives. Not evidence, not a template. It is the product.

## Inputs

| Source | File | Scope | Why |
|---|---|---|---|
| Stage 1 | `../01-research/output/` | the brief | the sources cited |
| Stage 2 | `../02-script/output/` | the script | narration as delivered |
| Stage 3 | `../03-production/output/` | the shot list | what the editor builds |
| Rule book | `../_config/style.md` | "Structure" | how it reads |

## Process

1. Check all three stage outputs exist for this slug. A missing one is a stop.
2. Assemble: what it is, the runtime, the three artifacts, the open questions.
3. Carry the open questions forward. Delivering them is honesty, not weakness.
4. Save it here, then append the ledger row.

## Outputs

| Artifact | Location | Format |
|---|---|---|
| Package | here, one file per slug | links to the three artifacts |
| Ledger line | `../_log/LOOP-LEDGER.md` | one appended row |

## Routing

| When | Go to |
