# Glossary

Layer 3 rule book. One word, one meaning. If a word is not here and it matters, add a proposal, do not improvise a second meaning.

## Workspace Vocabulary

| Term | Means here |
|---|---|
| job card | a stage `CONTEXT.md`. Never a prompt and never a skill |
| rule book | a file in `_config/`. It binds and no agent edits it |
| brief | the sourced answer written by `01-research`. The only place a fact enters |
| beat | one narration unit with a single idea and its own timecode |
| shot | one visual instruction attached to a beat |
| package | the folder a client receives, assembled in `output/` |

## Domain Terms

| Term | Means here |
|---|---|
| question | the one sentence a viewer would ask. Not a topic, not a title |
| claim | a sentence in the script that asserts something checkable |
| source line | the row in the brief that a claim points at |
| open question | something research could not settle. It is named, never smoothed over |
| runtime | the read-aloud duration of the narration, in minutes and seconds |

## When a rule is wrong

If a term is used two ways in one run, that is a hole, not a style choice. Write it into `../_log/FORGE-PROPOSALS.md` with both uses quoted.
