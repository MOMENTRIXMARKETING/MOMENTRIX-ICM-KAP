# Style

Layer 3 rule book for artifact formatting.

## Quick Reference

| Thing | Rule |
|---|---|
| Headings | sentence case, one `#` title per file |
| Dates | `YYYY-MM-DD` |
| Paths | full workspace-relative paths in job cards, relative links in artifacts |
| Tables | header row, alignment row, no trailing spaces |
| Claims | evidence row id in square brackets |

## Structure

A brief names the requested outcome and its boundaries. An evidence brief uses one row per claim with a direct raw-source link. A report states purpose, access and preparation, then open details. Do not hide an unresolved detail in a footnote.

## Code Fences

Use fences only for file trees or literal commands. Close every fence. Do not place commentary inside a command fence.

## When a rule is wrong

Append the artifact and the formatting conflict to `_log/FORGE-PROPOSALS.md`. Do not widen this rule book yourself.
