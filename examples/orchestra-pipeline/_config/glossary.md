# Glossary

Layer 3 rule book. One term, one meaning.

## Workspace Vocabulary

| Term | Means here |
|---|---|
| job card | a stage `CONTEXT.md`, never a skill or prompt |
| request | the external input bound to `@request` during intake |
| intake brief | the bounded request written by `00-intake` |
| evidence brief | the sourced claim table written by `01-research` |
| final report | the reviewed orientation written by `03-review` |

## Domain Terms

| Term | Means here |
|---|---|
| workshop | the fictional public-safe bicycle maintenance session in the raw captures |
| claim | a statement that must trace to an evidence row |
| evidence row | one row in the evidence brief naming its raw source |
| open detail | a fact the sources do not settle, stated without guessing |
| external action | a message, invitation, booking, purchase, or change outside this workspace |

## When a rule is wrong

If a term is used two ways, append both uses to `_log/FORGE-PROPOSALS.md`. Do not improvise a third meaning.
